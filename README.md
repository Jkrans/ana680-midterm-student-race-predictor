# ANA 680 Midterm – Student Race/Ethnicity Prediction

This project trains and deploys a machine learning model that predicts a student's race/ethnicity group (A–E) based on math, reading, and writing scores.

## Dataset
Student Performance in Exams (Kaggle):  
https://www.kaggle.com/datasets/spscientist/students-performance-in-exams
